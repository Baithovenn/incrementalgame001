# Startprompt für Claude Code / Codex im Browser

Diesen Text kannst du als ersten Prompt verwenden:

> Arbeite in diesem Repository. Lies zuerst die Projektregeln, `PROJECT.md` und die relevanten Skills. Nutze die vorhandenen Skills automatisch. Wir entwickeln ein neues Incremental Game von Grund auf. Beginne in der Ideen- und Game-Design-Phase; implementiere noch nichts, solange wir keinen konkreten Kernloop haben, den ein kleiner Prototyp sinnvoll testen kann.

Danach normal mit der eigentlichen Idee, Vorliebe oder Kritik weitermachen.
