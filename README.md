# incrementalgame001

Sauberes Entwicklungsrepository für ein neues Incremental Game.

Das Projekt ist bewusst noch **nicht** auf Thema, Mechanik oder Technik festgelegt. Die Idee soll zuerst tragen, bevor Code entsteht.

## Start

Für Claude Code und Codex liegen Projektregeln und Skills direkt im Repository.

- Claude Code: `CLAUDE.md` + `.claude/skills/`
- Codex: `AGENTS.md` + `.agents/skills/`
- Projektstand: `PROJECT.md`
- Spieldesign: `docs/GAME_DESIGN.md`
- Entscheidungen: `docs/DECISIONS.md`
- Aufgaben: `docs/BACKLOG.md`
- Browser-Startprompt: `BROWSER_PROMPT.md`

## Grundsatz

Tobias entscheidet, ob etwas interessant oder spaßig ist. Die Agenten sollen technische und gestalterische Lösungen selbst erarbeiten, Alternativen sichtbar machen und möglichst früh spielbare Evidenz erzeugen.
